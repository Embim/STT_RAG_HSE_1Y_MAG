# Карта тем — 3D-визуализация эмбеддингового пространства

Раздел **«Карта тем»** (`/space`) показывает корпус лекций как облако точек в
3D. Каждая точка — фрагмент (чанк) лекции; положение задаётся эмбеддингом,
снижённым до трёх измерений; цвет — авто-тема (кластер). Похожие по смыслу
фрагменты оказываются рядом — видно смысловые сгущения, которые могут
пересекать отдельные лекции.

## Что можно делать

- **Вращать / зумить** — мышью (OrbitControls), при простое камера медленно
  вращается сама.
- **Навести на точку** — всплывает лекция + фрагмент текста.
- **Кликнуть точку** — панель с фрагментом и ссылкой «Открыть фрагмент в видео»
  (источник + таймкод `start`).
- **Легенда тем** — клик по теме подсвечивает её точки.
- **Поиск** — вводишь запрос: top-K ближайших фрагментов «загораются» белым
  (это те же соседи, что вернул бы RAG-поиск через `near_text`), а золотой
  маркер-октаэдр показывает, куда спроецировался сам запрос.

## Как это устроено

Бэкенд (`src/system/embedding_map.py`):

1. Тянет векторы чанков из Weaviate (`include_vector=True`) — до
   `EMBEDDING_MAP_MAX_POINTS` (по умолчанию 5000).
2. **Снижение размерности до 3D.** UMAP (extra `viz`) — лучше разделяет
   кластеры; если `umap-learn` не установлен — fallback на PCA. Управляется
   `EMBEDDING_MAP_REDUCER` (`auto`/`umap`/`pca`).
3. **Кластеризация** (KMeans, k по эвристике √(n/2), 2…24) → авто-темы.
4. **Подписи тем** — топ-термины каждого кластера (c-TF-IDF с русскими
   стоп-словами).
5. Результат **кэшируется** в памяти вместе с обученным редьюсером; пересборка
   при изменении числа объектов в коллекции или `?force=true`.

Эндпоинты (за авторизацией):
- `GET /embedding-map[?force=true]` — облако: `points[]`, `topics[]`, `count`,
  `reducer`.
- `POST /embedding-map/locate` `{question, top_k}` — `highlight_ids` (точные
  соседи через `near_text`) + `marker` = центроид координат этих соседей (стоит
  среди подсвеченных точек; `null`, если соседей нет в текущей карте).

Фронтенд (`frontend/.../features/space/`) рендерит облако через **Three.js**
(WebGL `Points`), ленивым чанком — three не попадает в основной бандл.

## Установка

- `scikit-learn` — обычная зависимость (PCA/KMeans/TF-IDF), ставится всегда.
- UMAP — опционально: `uv sync --extra viz` (тянет numba/llvmlite). Без него
  карта строится на PCA. Первая сборка карты по тысячам векторов занимает
  секунды-минуты (nginx-таймаут для `/embedding-map` поднят до 300с), дальше —
  из кэша.
